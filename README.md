# RainGuard — Web

## Sobre

O RainGuard é um projeto acadêmico sobre prevenção de alagamentos. Esta parte do repositório reúne a página Web, que apresenta a proposta do projeto e permite consultar leituras demonstrativas.

## O que a página apresenta

- Informações sobre o problema, a tecnologia, os objetivos, o público-alvo e os benefícios do projeto.
- Um slideshow com imagens na seção Objetivos.
- Uma consulta demonstrativa de monitoramento por endereço.

Os dois endereços estudados exibem valores previamente definidos. Para outros endereços, a página gera valores aleatórios apenas para demonstração.

## Tecnologias

A página foi feita com HTML, CSS e JavaScript, sem frameworks.

## Como abrir

No VS Code, abra `gs front end/index/index.html` com a extensão Live Server.

## Limitações

A consulta não recebe dados dos sensores, não acessa uma API e não envia nem armazena informações. Os valores e estados exibidos servem somente para demonstrar a interface e a classificação proposta pelo projeto.

## Arquivos

- `gs front end/index/index.html`: estrutura da página.
- `gs front end/css/style.css`: estilos e adaptação para telas menores.
- `gs front end/js/script.js`: slideshow e consulta demonstrativa.
- `AI.md`: declaração de uso de inteligência artificial para JavaScript/Web.

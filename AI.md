# Declaração de uso de IA

Usei inteligência artificial como apoio pontual no desenvolvimento da parte Web do projeto RainGuard.

## Onde ajudou

- A pensar no funcionamento do slideshow com as imagens que já estavam na seção Objetivos.
- Em alguns trechos de JavaScript da consulta demonstrativa, como a validação do endereço e a classificação das leituras conforme os limites do projeto.
- Em ajustes de espaçamento, alinhamento e adaptação do CSS para telas menores.

A consulta é uma demonstração local: não recebe dados reais dos sensores, não acessa uma API e não envia nem armazena informações. Os integrantes devem revisar e compreender o código antes da apresentação.
